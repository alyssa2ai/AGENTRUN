# Provenance Directory

This directory holds the canonical, machine-checkable provenance record for the
published AGENTRUN experiment (Base / v1 / v2 on Qwen2.5-7B-Instruct).

Every file here is intended to be **read by a script**, not just by a human.
The canonical record is `experiment_provenance.json`; the `.md` files are
human-readable mirrors of parts of it.

## Labeling convention

Where the audit could not verify a fact from the repository or from a recorded
artifact, the fact is labeled explicitly:

| Label | Meaning |
|---|---|
| `VERIFIED` | Confirmed against a committed artifact (adapter config, result JSON, training script, timestamped log). |
| `INFERRED` | Reasonable inference from multiple consistent sources, but not directly confirmed by a single artifact. |
| `UNKNOWN` | No evidence exists in the repository; the value was never recorded. |

## Files

| File | Contents |
|---|---|
| `experiment_provenance.json` | Canonical provenance record (model, config, results, confound, environment, seeds). |
| `README.md` | This file. |
| `hyperparameters.md` | Human-readable mirror of the training-config section. |
| `seeds_and_determinism.md` | Human-readable mirror of the seed section. |

## How to regenerate

The JSON is generated from `results/experiment_summary.json` plus the committed
artifacts listed in each section. It is not auto-generated by a script today;
each field was hand-verified against the source artifacts during the Phase 1
audit (see `docs/experiment-log.md` for the audit trail).
