# Phase 5 — publication package

Turns the completed Phase 3 campaign and Phase 4 manuscript into a venue-formatted, submission-ready paper.
Start at `FINAL_SUBMISSION_README.md`.

**Nothing has been submitted anywhere, and no submission account exists.**

## What changed from Phase 4

| | Phase 4 | Phase 5 |
|---|---|---|
| Form | 16 Markdown section files, ~20{,}600 words | LaTeX paper on the official TMLR template, 30 pp |
| Length | everything in the main text | main text condensed; detail moved to appendices and a 9-page supplement |
| Figures | none | nine, all vector TikZ/PGFPlots, data generated from the analysis outputs |
| Tables | Markdown | nine typeset tables, long tables generated from CSV/JSON |
| Venue | none chosen | TMLR recommended, with four alternatives compared against official sources |
| Privacy | 160 files carried cluster identifiers | 42 documentation and script files scrubbed; 117 restricted artifacts preserved deliberately |

The Phase 4 manuscript is **not** deleted. It remains in `PHASE4/manuscript/` as the long-form record; Phase 5 is
a re-presentation of the same verified results, not a re-analysis. No number changed.

## Provenance rule

No value in the paper is typed by hand from a report. Figures read `.dat` files generated by
`figures_source/make_figure_data.py`, each carrying a `# source:` line naming the file and JSON path it came from;
the supplement's long tables are generated the same way. Table values in the main text were cross-read against
`PHASE3_DECISIONS.json` and the analysis JSON.

## Honest limits of this phase

1. **The bibliography was not re-verified against publisher records here.** Web search was unavailable; the 37
   entries are inherited unchanged from the earlier verification pass and no new reference was added.
2. **The venue candidate set was not discovered by systematic search.** Five candidates were chosen from knowledge
   and each verified against official pages; a better-fitting venue we did not think of would not have been found.
3. **Git history still contains the identifiers** that were scrubbed from the working tree. See
   `PRIVACY_SCRUB_REPORT.md`; a public release needs a filtered export or a history rewrite.
4. **Author, funding, acknowledgement and ethics fields are empty by design.** Nothing was invented.

## Tools

| Script | Purpose |
|---|---|
| `figures_source/make_figure_data.py` | extracts every plotted number from the analysis outputs |
| `figures_source/make_supplement_tables.py` | generates the supplement's long tables |
| `tools/package_qa.py` | privacy scan, font embedding, undefined references, overfull boxes, citations, provenance; writes `SOURCE_MANIFEST.sha256` |
| `tools/contact_sheet.py` | renders every page of a PDF into contact sheets for visual review |
| `tools/scrub_identifiers.py` | repository-wide identifier scrub, patterns loaded from a gitignored config |
| `tools/redaction.py` | shared redaction patterns, so no tracked file holds a real identifier |
| `tools/rebuild_phase3_manifest.py` | regenerates the Phase 3 hash manifest after a scrub |
