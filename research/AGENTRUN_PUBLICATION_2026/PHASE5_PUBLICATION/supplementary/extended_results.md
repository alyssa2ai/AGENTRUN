# Extended results

The typeset supplement is `submission/supplementary/supplementary.pdf` (9 pp), built from
`submission/supplementary/supplementary.tex`. This file is a pointer, not a second copy: keeping one source
avoids the two drifting apart.

| Content | Where |
|---|---|
| Every contrast, on every item set (6 analyses x 11 contrasts) | supplement §2.1, generated as `tab_s_contrasts.tex` |
| Every model x condition cell (72 rows) | supplement §2.2, generated as `tab_s_permodel.tex` |
| Task success by model, decoding and condition | supplement §2.3, generated as `tab_s_decoding.tex` |
| Condition-level rates behind Figures 6 and 8 | main paper Appendix B, Table 9 |
| Benchmark construction and annotation protocol | supplement §1 |
| Deviation record, by epistemic status | supplement §3 |
| Reproduction instructions | supplement §4 |

All three long tables are generated by `figures_source/make_supplement_tables.py` directly from
`PHASE3/results/*.csv` and `PHASE3/ANALYSIS/*.json`. Re-run it if the analysis is ever re-run.

**Not included, deliberately:** eval3 task text, gold labels, per-run transcripts, cluster logs, credentials and
infrastructure identifiers.
