## 3. What is genuinely supported by current evidence

All figures below were recomputed in this session from raw run records (see STATISTICAL_VALIDATION.md):

1. **The committed Campaign 2 tables reproduce exactly.** Re-running `scripts/analyze_c2.py` on `raw_results/c2_*` regenerates `tables/c2/C2_TABLES.md` byte-identically (modulo CRLF).
2. **Memory helps (large, robust).** Pooled v1: +32.3 pp (family-clustered 95% CI +10.9 to +55.1); significant at every size from 3B up, both harnesses.
3. **A text-only verifier hurts task success** (−5.2 pp v1, −11.5 pp v2 pooled; family-clustered CIs exclude 0) while catching some fabrications (6 correct rejections of the invented 12500.00 drafts under v2 — verified in transcripts).
4. **The deterministic reliability gate helps at 7B** (+13.0 pooled v1, +16.7 pooled v2; family-clustered CIs exclude 0), driven by stale-record scenarios (S4: 32/32 with v2+E).
5. **The harness fix is real and quantified**: +15.8 pp on both models (family-clustered CIs +4.0/+3.3 to +28/+29.5); Qwen3-8B never used the repair turn, so its gain is attributable to the two prompt rules; the Qwen2.5-7B split awaits jobs 15–16 (v1r).
6. **The abstention failure mode is step-limit looping, not fabrication.** Verified in transcripts: Qwen3-8B v1 config E answered 1/16 unsupported questions; the 15 failures are all `max_steps` with 0 unsupported claims. v2 recovers 16/16.
7. **Retrieval collapse propagates end-to-end**: hash256 at +2,000 records −29.7 pp (family-clustered CI −47.8 to −12.6); BM25 restores +28.6 pp. (Caveat: only 16 families contribute; dense retriever missing.)
8. **Capacity dependence is non-monotonic** for the reliability components (nothing at 1.5B/3B, large at 7B, small at 14B) while memory helps from 3B up. Verified including the detail findings: 1.5B called `memory_search` 0/256 times; 14B's step-limit failures include repeated `round(...)` calculator rejections; 14B wrote partial Thai reasoning in >55% of runs (serving-stack interaction unresolved).
9. **The V2 adapter's 23/23 is evaluation adaptation, not generalization**: reproduces 5/5 with a matched client, but on 55 fresh tasks the adapter is 92.7% vs base 94.5% (n.s.). Never cite 23/23 as generalization evidence.
10. **The first 48-task study replicates** on the fresh 96 tasks with the frozen v1 harness, and Part 6.1/6.2 numbers in the project brief match the committed RESULTS.md exactly.
